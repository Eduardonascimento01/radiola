# Radiola

Meu app de música. Funciona no navegador, no PC e no celular.

O nome vem da radiola antiga, que juntava rádio e toca-discos num móvel só. A ideia é a mesma: juntar várias fontes de música num lugar só.

## O que já faz
- Toca as músicas que estão no seu aparelho
- Mostra o nome, o artista e a capa da música
- Tem fila, aleatório e repetir
- Lembra onde você parou
- As músicas ficam só no seu navegador, nada vai para a internet
- Dá para instalar no celular como aplicativo

## O que vem depois
- Músicas grátis do Audius
- Rádios ao vivo
- YouTube e Spotify
- Trazer as playlists de outros apps

## Como rodar
Na pasta do projeto:

```
python -m http.server 8000
```

Depois é só abrir http://localhost:8000

Para rodar os testes: `node teste.js`
